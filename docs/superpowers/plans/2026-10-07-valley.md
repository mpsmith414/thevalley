# The Valley Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A 1.6 km northern temperate valley (layout-driven terrain with erosion, a lake fed by a river, code-built trees and plants with CC0 textures, a running day and night, an ambient soundscape and 18 resident native animals) that you fly around with a controller at 1080p and 60 fps, on `index.html`, with the Creature Lab moved to `lab.html`.

**Architecture:** Pure, tested modules generate the world from a hand-written layout and a seed: terrain, erosion, water carving, biomes, plant geometry and scattering. They run in a Web Worker, and the result (`ValleyData`) is cached in IndexedDB. A `Valley` query object answers ground and water questions for every system. The main thread draws the world with three.js WebGPU (TSL): a clipmap terrain, lake and river meshes, instanced vegetation in 64 m tiles with impostors far away, GPU ground cover, a SkyMesh sky with stars and moon, and cascaded shadows. Residents reuse the lab's builder, rig and `ActionController` through a new `Habitat` interface.

**Tech Stack:** Node 24, TypeScript, Vite 8, Vitest 5, three 0.186 (`three/webgpu`, `three/tsl`, `three/addons`: `SkyMesh`, `CSMShadowNode`, `reflector`), idb 8, fake-indexeddb (tests), Web Audio API.

## Global Constraints

- Specs: `docs/superpowers/specs/2026-10-07-valley-design.md` (this sub-project) and `docs/superpowers/specs/2026-10-06-vision-and-roadmap.md`.
- **World frame:** metres. `+y` up, `+x` east, `+z` south. The valley is centred on the origin: `x, z ∈ [−800, 800]` (`size = 1600`). The lake surface is `y = 0`.
- **Grids:** the height grid has `grid` samples per side (default **2049**, so `cell = size / (grid − 1) = 0.78125 m`). Sample `(ix, iz)` sits at `x = −size/2 + ix·cell`, `z = −size/2 + iz·cell`, index `iz·grid + ix`. The **map grid** (water, biomes) is `mapGrid = (grid − 1) / 2 + 1` (1025 by default) with `mapCell = 2·cell`. Tests use `grid = 257` or `513`. Every generator takes `grid` as a parameter and **never** assumes 2049.
- **Determinism:** no `Math.random` in `src/valley`, `src/plants` (except rendering-only shader hashes) or `src/residents`. Use `mulberry32` from `src/util/rng.ts` and `hash` / `hashNumbers` from `src/util/hash.ts`. The same layout and `GENERATOR_VERSION` give an identical `ValleyData` hash.
- **`GENERATOR_VERSION`** (in `src/valley/types.ts`) starts at `1`. Bump it whenever any generator output changes; it is part of the cache key.
- **Tiles:** 64 m square, `TILES = 25` per side, tile `(tx, tz)` covers `x ∈ [−800 + 64·tx, −736 + 64·tx)`.
- **Performance:** High tier holds 60 fps at 1080p on the RTX 3060 Ti with dynamic resolution. First-visit generation is under 15 s; cached loads take a couple of seconds.
- **WebGPU limits:** at most 8 vertex buffers and 12 uniform buffers per shader stage. Pack per-vertex and per-instance data into `vec4` attributes.
- **Assets:** CC0 only. Every file in `public/assets/` is listed in `public/assets/CREDITS.md` with source URL and licence. **Downloading any asset requires the owner's OK first** (state the files, source and total size). If an asset is missing at runtime, the code falls back (painted in code or synthesised) instead of failing.
- **Tone:** kid-facing text is short, warm and family-friendly.
- **Input:** controller first. Keyboard and mouse must reach every function.
- **Git:** work on branch `feat/valley`, created from `feat/creature-lab`. Never merge to `main` without the owner's OK. Commit messages end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.
- **Checks before every commit:** `npm test` green and `npx tsc --noEmit` clean.

### Task 2: Terrain shape and erosion

**Files:** create `src/valley/generate/shape.ts`, `src/valley/generate/erosion.ts`, `tests/valley/shape.test.ts`.

**Interfaces:**
- Consumes: `Layout`, `createNoise2D`, `fbm`, `ridged`, `sdPolygon` and the polyline helpers.
- Produces:
  - `type HeightGrid = { grid: number; size: number; cell: number; h: Float32Array }`, plus `sampleHeight(g: HeightGrid, x: number, z: number): number` (bilinear, clamped to the border) and `gridIndex(g, ix, iz)`.
  - `baseShape(layout: Layout, grid: number): HeightGrid`. For each sample:
    - **Bowl:** `layout.floor + layout.rim · smoothstep(0.55, 1.0, max(|x|, |z|) / (size / 2))`.
    - **Ridges:** for each ridge, `d` = distance to its polyline (or point). Add `height · bump(d / width)`, with `bump(t) = t < 1 ? (1 − t²)² : 0`. Take the max of the ridges, not the sum, so crossing ridges don't stack.
    - **Noise**, scaled by `relief = smoothstep(2, 30, h_so_far − floor)`:
      - `+ (1.5 + 10·relief) · fbm(n, x/220, z/220, 5)`
      - `+ rockyAt · 18 · relief · ridged(n2, x/90, z/90, 4)`, where `rockyAt` is the `rocky` value of the nearest ridge weighted by its bump.
  - `erode(g: HeightGrid, seed: number, droplets = Math.round(160_000 · ((g.grid − 1) / 2048) ** 2)): void`: in place, Beyer-style droplet erosion. Parameters: inertia 0.05, capacity 4, minSlope 0.01, erode 0.3, deposit 0.3, evaporate 0.02, gravity 4, maxSteps 64, brush radius 2 cells. Droplet start positions come from `mulberry32(seed ^ 0x9e3779b9)`.

  - `erode`: deterministic; the total height change is negative (material leaves the grid at the edges or settles), but the mean change is under 1 m; the max slope on a test sample along the east hills drops (erosion smooths spikes); no NaN.

### Task 3: Carving the lake and the river

**Files:** create `src/valley/generate/carve.ts`, `tests/valley/carve.test.ts`.

**Interfaces:**
- Consumes: `HeightGrid`, `sampleHeight`, `Lake`, `River`, `catmullRom`, `sdPolygon`, the polyline index.
- Produces:
  - `type RiverSample = { x: number; z: number; s: number; surface: number; width: number; slope: number; tx: number; tz: number }`, with samples every 2 m.
  - `type WaterMaps = { mapGrid: number; level: Float32Array /*NaN = dry*/; flow: Float32Array /*2 per cell: x, z in m/s*/; kind: Uint8Array /*0 dry, 1 lake, 2 river*/ }`.
  - `carveWater(g: HeightGrid, layout: Layout): { river: RiverSample[]; water: WaterMaps }` mutates `g.h` in this order:
    1. **River profile.** Resample the course with `catmullRom(points, 2)`. Read the terrain under each sample: `t_k`. Then `surface_0 = t_0 − 0.3` and `surface_k = min(surface_{k−1} − 0.002 · ds, t_k − 0.3)`. Clamp to `≥ lake.level`. The final sample is `lake.level`. Width `= lerp(width0, width1, s / total)`. `slope_k = (surface_{k−1} − surface_k) / ds`, smoothed over ±3 samples.
    2. **River bed and banks.** For each grid cell within `width/2 + 8` of the course (use the polyline index), find the nearest sample `k` and distance `d`:
       - if `d < w/2`: `h = min(h, surface_k − depth · (1 − (d / (w/2))²) − 0.05)`;
       - else: `h = min(h, surface_k + 0.3 + (d − w/2) · 0.35)`.
    3. **Lake basin.** For `sd = sdPolygon(cell, outline)`:
       - if `sd < 0`: `h = min(h, level − 0.3 − (depth − 0.3) · smoothstep(0, 60, −sd))`;
       - if `0 ≤ sd < 40`: `h = min(h, level + 0.2 + sd · 0.12)`.
    4. **Beach.** Inside the beach area and within 40 m of the lake, cap the slope at 5%: `h = min(h, level + 0.15 + sd · 0.05)`.
    5. **Dry land stays dry.** Every cell that is neither lake (`sd < 0`) nor river channel (`d < w/2`) gets `h = max(h, level + 0.2)`.
  - The water maps are built on the map grid. Lake cells: `kind 1`, `level = lake.level`, flow 0. River cells (`d < w/2`, not lake): `kind 2`, `level = surface_k`, `flow = tangent · clamp(0.4 + 6 · slope, 0.4, 2.5)`.
- [ ] **Step 1: failing tests** (`grid = 513`, after `baseShape` and `erode`):
  - `river[k].surface` is non-increasing in `k` and the last one equals `level`;
  - every river sample's bed (`sampleHeight`) is below its surface;
  - every lake-polygon cell centre is below `level − 0.25`;
  - every map cell with `kind 0` has height ≥ `level + 0.19`;
  - for 500 random dry cells within 30 m of the lake, height < `level + 0.2 + 30 · 0.12 + 0.01` (gentle shores);
  - the result is deterministic (`hashNumbers` of `h` and `level`).
- [ ] **Step 2:** the tests fail. **Step 3:** implement. **Step 4:** the tests pass.
- [ ] **Step 5:** commit `feat(valley): carve the river and lake so water always runs downhill`.

### Task 4: Biomes, normals and the `Valley` query object

**Files:** create `src/valley/generate/biomes.ts`, `src/valley/valley.ts`, `tests/valley/biomes.test.ts`, `tests/valley/valley.test.ts`.

**Interfaces:**
- Consumes: `HeightGrid`, `WaterMaps`, `RiverSample`, `Layout`, the noise and geometry helpers.
- Produces:
  - `computeBiomes(g, water, layout): Uint8Array`: map grid, 6 bytes per cell (forest, meadow, rock, shore, beach, moisture), each 0–255. Per cell:
    - `slope` in degrees, from the height grid;
    - `wd`, the distance to water in m, from a two-pass chamfer distance transform over `kind ≠ 0`;
    - `moisture = exp(−wd / 40)`;
    - perturb every area's `sdPolygon` by `15 · fbm(x/60, z/60, 3)` for organic edges;
    - `rock = max(smoothstep(28, 40, slope), smoothstep(150, 175, h), rockArea · smoothstep(10, 25, slope))`;
    - `beach = beachArea · smoothstep(40, 5, wd)`;
    - `shore = (1 − rock) · smoothstep(12, 2, wd) · (1 − beach)`;
    - `meadow = meadowArea · (1 − rock) · (1 − shore) · (1 − beach)`;
    - `forest = max(0, 1 − rock − beach − shore − meadow)`.
    - Normalise the five to sum to 1, then quantise. Water cells get `shore = 1`.
  - `computeNormals(g): Uint8Array`: full grid, RGBA8. RGB is the normal mapped from [−1, 1] to [0, 255]. A is cavity: `clamp(0.5 + (avg of the 8 neighbours − h) · 0.25, 0, 1) · 255`.
  - `type TileData = { tx: number; tz: number; plants: PlantInstances; trunks: Float32Array /*x, z, r triples*/ }` (`PlantInstances` comes in Task 6; declare it here in `types.ts` as `{ kind: Uint8Array; variant: Uint8Array; data: Float32Array }` with `INSTANCE_STRIDE = 10`: x, y, z, yaw, scale, leanX, leanZ, tint, age, health).
  - `type ValleyData = { version: number; key: string; size: number; grid: number; height: Float32Array; normals: Uint8Array; water: WaterMaps; biomes: Uint8Array; river: RiverSample[]; tiles: TileData[]; plantModels: PlantModelSet }` (`PlantModelSet` comes in Task 5; for now declare it as `unknown[]` in `types.ts`, and Task 5 narrows it).
  - `createValley(d: ValleyData): Valley`:

